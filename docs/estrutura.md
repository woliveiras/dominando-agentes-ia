# Estrutura do Livro: Dominando Agentes de IA

**Guia Prático para Construção de Sistemas Inteligentes e Autônomos para Produção**

---

## 📖 Como Este Livro Funciona

### Foco 100% em Agentes de IA

Este livro ensina a **construir agentes de IA** do zero até produção. 

Para que você possa focar completamente nos agentes, eu forneço toda a estrutura não relacionada a agentes já pronta.


```
┌─────────────────────────────────────────────┐
│  Você NÃO aprende (já vem pronto):          │
│  • Como fazer API REST em FastAPI           │
│  • Como criar UI em React                   │
│  • Como configurar PostgreSQL               │
│  • Como fazer deploy de containers          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│  Você APRENDE (foco do livro):              │
│  • Como construir agentes inteligentes      │
│  • Como usar LLMs efetivamente              │
│  • Como criar tools e workflows             │
│  • Como orquestrar multi-agentes            │
│  • Como garantir segurança e qualidade      │
│  • Como fazer deploy em produção            │
└─────────────────────────────────────────────┘
```

### Público-Alvo

Este livro é para **pessoas engenheiras de software** que desejam:

- Dominar a construção de sistemas integrados ou baseados em agentes de IA
- Entender teoria e prática de forma equilibrada
- Construir sistemas reais, não apenas tutoriais estilo "hello world"
- Aplicar conhecimento em ambientes de produção, projetos pessoais ou startups

### Pré-requisitos

Recomendo que você tenha (mas não obrigatório para entender a parte teórica):

- Conhecimento em Python intermediário/avançado
- Conhecimentos de APIs REST
- Experiência com Docker (básico)
- Familiaridade com conceitos de machine learning (desejável, mas não obrigatório)

## 💡 Estrutura dos Capítulos

Cada capítulo do livro segue o padrão:

### 1. Conceito (Teoria - 20%)

- Por que este conceito é importante
- Como funciona
- Best practices

### 2. Implementação (Prática - 60%)

- Código passo-a-passo
- Explicações detalhadas
- Como testar via CLI

### 3. Integração (Sistema - 20%)

- Como integra com outros agentes
- Como ver funcionando na Web UI
- Exercícios práticos

## 🎯 Progressão de Aprendizado

```
Capítulos 1-4: Fundamentos
↓ Você constrói: TriageAgent básico
↓ Você aprende: LLMs, prompting, embeddings

Capítulos 5-6: RAG e Tools
↓ Você adiciona: MatchingAgent + tools
↓ Você aprende: RAG, function calling, APIs

Capítulos 7-8: Workflows e Multi-Agent
↓ Você adiciona: 3+ agentes coordenados
↓ Você aprende: Orquestração, MCP, consensus

Capítulos 9-13: Produção
↓ Você otimiza: Sistema completo
↓ Você aprende: Scaling, segurança, monitoring
```

## 🎓 Para o Leitor

### O Que Esperar

✅ **Código Production-Ready**: Não é toy project, é código que você pode usar em produção  
✅ **Teoria + Prática**: Entenda o "porquê" e o "como"  
✅ **Progressão Clara**: Cada capítulo adiciona uma camada de complexidade  
✅ **Open Source**: Todo código disponível no GitHub  
✅ **Impacto Real**: Sistema que pode ajudar hospitais reais

### O Que NÃO Esperar

❌ Tutorial de React ou FastAPI (infraestrutura já vem pronta)  
❌ Código simplificado demais (é production-ready de verdade)  
❌ Foco em teoria pura (é hands-on com base teórica forte)

## 📖 Como Usar Este Livro

1. **Setup inicial**: Siga o Quick Start (2 minutos)
2. **Leia o capítulo**: Entenda a teoria
3. **Implemente o código**: Siga os exemplos
4. **Teste via CLI**: `medscheduler test agent-name`
5. **Veja na Web UI**: Visualize funcionando
6. **Faça os exercícios**: Pratique mais
7. **Próximo capítulo**: Continue evoluindo o sistema
