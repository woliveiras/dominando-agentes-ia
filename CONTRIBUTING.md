# Contribuindo

Ao contribuir com este repositório, por favor, primeiro discuta a mudança que você deseja fazer por meio de issue, e-mail ou qualquer outro método com os mantenedores deste repositório antes de fazer uma alteração.

Por favor, observe que temos um [Código de Conduta](CODE_OF_CONDUCT.md). Siga-o em todas as suas interações com o projeto.

## Processo de Pull Request

1. Certifique-se de que qualquer dependência de instalação ou construção seja removida antes do final da camada ao fazer uma build.
2. Certifique-se de que seu trabalho está completamente testado, de acordo com suas melhores habilidades.
3. Para revisões de conteúdo do livro:
   - Verifique ortografia e gramática
   - Teste todos os exemplos de código incluídos
   - Certifique-se de que os exemplos seguem os padrões do projeto
   - Verifique se as referências bibliográficas estão corretas e completas
4. Envie um pull request detalhando suas mudanças e o motivo delas.
5. Seu pull request será revisado e discutido antes de ser mesclado.
6. Seu pull request pode ser fechado se não seguir as diretrizes acima.
